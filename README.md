# hanif-dossier.github.io — halaman utama

Satu pintu ke semua laporan Hanif Investment Service. Halaman statis tanpa
pustaka: `index.html` membaca markdown terbaru dari repo `laporan-harian` dan
`potret-pasar-crypto` (alamat yang sama, jadi bisa diambil langsung) lalu
menampilkan cuplikan hidup: angka pasar, koinmu hari ini, peringatan terbaru,
dan daftar pendek screening.

Tautan yang dituju:

- https://hanif-dossier.github.io/laporan-harian/ — Briefing Harian
- https://hanif-dossier.github.io/laporan-harian/radar.html — Radar Portofolio
- https://hanif-dossier.github.io/laporan-harian/peringatan.html — Peringatan
- https://hanif-dossier.github.io/potret-pasar-crypto/ — Screening Altcoin

Tidak ada jadwal di repo ini; isinya berubah sendiri karena data dibaca saat
halaman dibuka.
